# Вхідний сценарій: оплата інвойса

Постановка задачі «як є», з якої виріс дизайн у
[event-driven-architecture.md](../event-driven-architecture.md). Збережена дослівно —
щоб було видно, на що саме відповідає той документ.

---

Припустимо сталась така подія: оплаченний інвойс. Ми менюємо в транзакції Status інвойса на "Оплаченний".

Далі потрібно створити події в черзі для неоплаченого інвойсу з усіма деталями

далі потрібно зробити операцію по обліку

відправити емейл клієntу про оплачений інвойс

змінити баланс клієнта

інший сервіс, який відповідає за провідження них, повинен підключити кастомеру якийсь сервіс

далі потрібно відправити нотифікацію клієнту в браузер, який має відкриту CRM.
