# Files and avatars

## Where you can upload files

Today the only upload in the interface is a **profile picture (avatar)**:

- your own: User settings → "Profile" → "Avatar" → "Change" (and "Remove");
- someone else's: Workspace → "Users" → row menu or user page → "Change avatar".

Drop an image on the drop zone ("Drop a file here or choose one") or click "Choose file".

## Allowed images

JPEG, PNG, WebP or GIF. Keep the image under 10 MB, as the Profile page says. A small preview
is generated automatically.

## Upload errors

- "This file type is not allowed" — the file is not one of the image types above.
- "File is too large (max … MB)" — choose a smaller image.
- The file's content is checked after upload: a file whose content does not match its type
  (for example a renamed PDF with a `.png` extension) is rejected.
- "Could not set the avatar, please try again" — the upload did not finish; try again.

## How files are protected

Files are not public. Each time a file is shown, the application creates a short-lived private
link that stops working after a few minutes, so copying an image address and sharing it does
not give lasting access. Uploads that were started but never finished are cleaned up
automatically after a day.

## Not available

You cannot attach documents (PDF, Word, Excel or others) to customers, events or chat
messages, and there is no file library or shared drive. Chat has no attachments yet.
